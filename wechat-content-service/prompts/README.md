## 对话长文

两个朋友夜里聊感情，把“不够爱”“不合适”这类现成解释换成一句更准的话。可以借一个典故的新读法，也可以只靠一样贯穿全文的具体东西；典故对不上位就不用，不硬凑。在管理界面里它是情感文章的一个内容方向（“对话长文”），和“清醒短句”一样，选它换的是写法而不是话题。

### 一篇是怎么出来的

1. 选题：模型从典故库里随机抽到的十二条里挑一条对得上位的，写成“典故名｜处境”；都对不上就不用典故，只写处境，切入点里写“典故：无”和贯穿全文的那样东西。切入点还包括写法、靶子、论点、落点、人物。近三十篇用过的典故不会再出现在备选里。
2. 审阅：选题和切入点先给人看，可以改。
3. 成文：写作规范加上被点名的那一条典故（情节、可引的原句、边界）一起发给模型。切入点写了“典故：无”时不带任何典故；什么都没说时给六条备选，并告诉模型对不上就不用。
4. 改稿：勾选润色时，用一张对照清单再过一遍，典故仍以库里的条目为准。
5. 整理：引号统一成中文引号，一个字符串里的两段拆开，小标题清空。文字本身不动。

代码在 `app/services/dialogue_essay.py`。

### 不经过管理界面直接出稿

```bash
python scripts/write_dialogue_essays.py --env-file ../.env --provider deepseek --count 5
```

每篇写出 `.txt`（正文）、`.html`（排版预览）、`.json`（选题、切入点、模型和完整结构）。同一个输出目录里已有的稿子算“近期用过”，所以多跑几次也会在典故库里换着用。

`dialogue_essay.md` 本身就是一份完整的提示词：整份贴进任何模型的系统提示，再把选题发过去，会按文末“输出”一节返回纯文本。流水线用的是“输出”之前的部分，另接 JSON 结构。

### 例文放哪里

例文不进版本库：这个仓库是公开的，例文可能是别人的作品。放在本机的 `prompts/samples/dialogue_essay/` 下（`.txt` 或 `.md`，该目录已被 git 忽略），成文时会随机带上一篇，只让模型学结构、节奏和排版。也可以在管理界面的“参考文字”里临时贴一篇，作用相同。

### 往典故库里加条目

照现有条目的字段写，标题行下面可以加一行 `别名：甲、乙`，方便手填的选题对上条目。三条规矩：

- 情节和原句要对着原文核过再加，凭记忆写的不算。库里现有 45 条在 2026-11 核对过一轮并据此改过：20 处原句逐字对过，情节和出处逐条对过。对照的是检索返回的原文片段，没有逐页打开原文；《西西弗神话》和《小王子》两条只对到了二手页面。
- “可用读法”是文章里“我”的看法，写的时候不要把它说成原文本意；涉及版本分歧、相传之说的，在“边界”里写明。
- 条目名不能是别的条目名或别名的一部分，也不要用一个字的名字，否则对不上号。

### 跑 MiniMax Token Plan 要注意

- 速率限制会把请求的输出上限算进去：上限 16384 时长文请求每次立刻被拒（2062），8192 能通过；一篇对话长文实际输出约 2000 token。
- 长文要写 40 秒以上，非流式请求会被网关在约 30 秒时掐断（502），所以 MiniMax 走流式。
- 每成功一个长文请求后要冷却很久（实测十几到二十几分钟）。批量时用 `--pause 1200`，或者换按量付费的 key。
- 为了少占限额，成文只发选定写法的骨架，改稿不再重发整份规范：两次请求合计从约 1.8 万字降到约 1.2 万字。
- 限流看起来按模型分开算：选题 M2.7-highspeed、成文 M3、润色 M3.1-Flash 连着发没有被拒，全用 M3 时几乎每步都被卡。批量脚本用 `--models MiniMax-M2.7-highspeed,MiniMax-M3,MiniMax-M3.1-Flash`。

### 规范是从哪里量出来的

规范里的数字来自两篇例文，用 `scripts/essay_shape.py` 量的。以后拿到新例文，用同一把尺子再量，偏得多了再改规范。

| | 例文一（解惑体） | 例文二（自述体） |
| --- | --- | --- |
| 汉字 / 含标点 | 2218 / 2624 | 2446 / 2796 |
| 段数 | 106 | 91 |
| 每段汉字 均值 / 中位 / 最长 | 21 / 20 / 63 | 27 / 18 / 115 |
| 引号内的字数 | 81% | 37% |
| 段内换行的段 | 42% | 0% |
| 不超过 12 字的段 | 25% | 34% |
| 60 字以上的段 | 1% | 13% |
| 问号 / 破折号 / 省略号 | 16 / 1 / 1 | 20 / 0 / 0 |
| 典故或引语出现的位置 | 5%，意象用到最后一句 | 32%，只是一句读过的话 |

两篇各拍结束的位置：

- 例文一：靶子 5%，典故讲完 10%，翻案 24%，朋友的经历 45%，对上 59%，朋友不服 70%，如果 85%，朋友自己说出来 90%，离场 95%，对读者说 100%。
- 例文二：第一段独白 8%，问原因 15%，靶子和论点 21%，展开 32%，引一句话 39%，被朋友照出来 52%，拆掉答案 65%，假设题 79%，不甘心 85%，散场 95%，收住 100%。

两篇共有而规范里写死的几条：只有“我”和朋友两个人、不起名字；朋友先说出“不够爱”再被推翻；论点是在分清两样东西；没有坏人，也不许诺复合。
